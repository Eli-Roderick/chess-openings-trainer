# P00 corrections (from the P00 build thread, 2026-10-06)

1. **Stockfish version.** Plan says 17.1 "at the time of writing". Latest tag is `sf_19`, but its release has no downloadable assets under the expected names (all 404). Pinned **sf_18**, whose assets exist with exactly the names in 05-engine.md §1. Archive layout: `stockfish/stockfish-<asset-name>[.exe]` inside each tar/zip.
2. **Package versions.** `flutter pub add` initially resolved `chessground 9.0.0` / `dartchess 0.12.3` because of a stale constraint; upgraded to the latest stable `chessground ^10.3.0`, `dartchess ^0.14.0`. `very_good_analysis ^11.0.0`.
3. **Flutter 3.47.6 / Dart 3.13.5.** The lint `unnecessary_type_name_in_constructor` (in very_good_analysis 11) requires the new `const new({super.key});` constructor syntax instead of `const ClassName({super.key});`. Agents must write constructors that way or `flutter analyze --fatal-infos` fails. `dart fix --apply` converts them.
4. **Workspace root.** The root `pubspec.yaml` lists `workspace:` and must NOT have `resolution: workspace` (only the packages do).
5. **l10n.** `synthetic-package` is removed in this Flutter; `l10n.yaml` uses `output-dir: lib/l10n/gen` (committed, excluded from analysis) and `pubspec.yaml` needs `flutter: generate: true`.
6. **Engine-tagged tests.** Plain `dart test` in `packages/uci_engine` must run with `--exclude-tags engine` in the checks job (the binary is only fetched in the engine-integration job).
