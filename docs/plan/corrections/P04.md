# P04 corrections (from the P04 build thread, 2026-10-06)

1. **Import isolate.** P04 task 6 says `Isolate.run`. `Isolate.run` can neither report progress stages nor be stopped, and the Create screen needs both (stage text, Cancel). The import runs in an `Isolate.spawn` worker that sends each `ImportStage` over a port and the result with `Isolate.exit`; Cancel kills the isolate and drops the result. `importPgn`/`importPgnBytes` in `chess_core` gained an `onStage` callback (reading, parsing, building lines, checking comments). The runner lives in `lib/core/import/` because Create, re-import, the demo install and "Validate stored PGN" all use it. (D-63)
2. **Cold start "on a Linux release build".** `flutter test` has no release mode and Flutter Driver refuses desktop release builds ("does not support running in release mode; use --profile"). The 1 s budget is checked AOT-compiled in profile mode with `flutter drive --profile` (`integration_test/cold_start_test.dart`, `test_driver/integration_test.dart`); under `flutter test` (debug, JIT) the same test only checks a 5 s bound. Measured on the build container: 145 ms in profile mode, about 2 s in debug. (D-61)
3. **Integration test files.** `flutter test integration_test -d linux` with two files fails reliably on the second one ("Error waiting for a debug connection: The log reader stopped unexpectedly"). CI starts one app per file. (D-62)
4. **Static board.** "chessground in non-interactive mode" is `StaticChessboard` (chessground 10). The preview dialog replays the SAN path from the start position with dartchess.
5. **Settings sections not built yet** (Training, Engine, Board, Sync, Data) open a page that says the settings arrive in a later version, so every section header in 01 §10 is reachable now.
