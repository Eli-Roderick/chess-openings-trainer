# P11 corrections (from the P11 build thread, 2026-10-06)

1. **Gzip adapter outside chess_core.** Task 2 keeps `dart:io` "behind a small adapter" in chess_core, but the architecture test forbids `dart:io` anywhere in chess_core's `lib`. The codec takes a `GzipCodec`; the `dart:io` implementation lives in the app (`lib/core/sync/io_codec.dart`). (D-105)
2. **Backups of 20k runs do not fit the budgets through Dart objects.** Loading 20k runs with their ~120k grades, encoding them with `toJson`, and inserting them back took 5.4 s to export and 75 s to import (profile build, Linux), against 3 s / 5 s. The bulk paths now run in SQLite: export builds the runs' JSON with `json_object` (same form as `RunRecord.toJson`, including the snake_case check status) and the codec splices it into the backup; import sends the unpacked text to SQLite once, keeps it as JSONB in a temporary table, checks format, schema and run ids there, and inserts runs, grades and deviations with `jsonb_each` in one transaction. Result: export about 1.0 s, import about 3.2 s. The round-trip test compares every column, deviations and check statuses included. (D-106)
3. **Derivation without grades.** Re-deriving after an import loaded every run with grades only for `RunRecord.allPerfect`. Credits are at most 1, so "every credit is 1" equals `creditSum == gradedCount` (with `gradedCount > 0`); `allPerfect` now uses the totals and the stats service loads runs without grades (`runsForDerivation`).
4. **Run inserts are batched.** `insertIfAbsent` (sync and merges) inserted one run per database round trip; it now writes 500 runs per batch.
5. **Sync warning on Replace all.** 06 §8 warns on Replace when Drive sync is on. Sync arrives in P12, so the warning is added there; P11 shows the plain confirmation with the local counts.
6. **Sync and backup screen in its own feature.** Features may not import each other, so Settings → Sync and backup is `features/backup/sync_backup_screen.dart`, routed by the router for `/settings/sync`.
7. **Settings restore.** "Also restore settings" applies every stored setting except `engineVariant`, which describes the machine (AVX2 or SSE4.1 build), not a preference.
