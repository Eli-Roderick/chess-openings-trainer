# P12 corrections (from the P12 build thread, 2026-10-06)

1. **Sync lives in `core/sync`.** 06 §4 names `features/sync/sync_service.dart`, but the backup screen (Settings), Home (status icon) and the drill (deferral) all need it, and features may not import each other. Transport, auth, service, controller and the lifecycle hook are in `lib/core/sync/`; only screens stay in features. (D-107)
2. **One merge per sync.** 06 §4 merges file by file. The service downloads and decodes every changed file first, then merges all records and runs in one `MergeApplier` call (one transaction, one re-derivation per repertoire) and caches the files' md5 afterwards. Same result, less work, and nothing is half-applied when a later download fails.
3. **Newer-schema and corrupt files are not cached.** Their md5 is not stored, so after an app update the skipped file is read on the next sync.
4. **Account e-mail from Drive.** The desktop flow with only the `drive.appdata` scope does not return the user's e-mail; both platforms ask Drive (`about.get user.emailAddress`) instead.
5. **Desktop token refresh.** `googleapis_auth`'s auto-refreshing client renews tokens by itself and its credential updates are saved; a 401 there means the refresh token is gone, so the status becomes "Sign in again" without a second attempt. On Android a 401 triggers one silent token request and one retry of the sync.
6. **Isolate entry points.** A closure created inside a method captures every variable of its scope that some closure captures, including the Drive client, which cannot be sent to an isolate. Encoding and decoding use top-level functions that capture only their data.
7. **Merging on the UI isolate.** Decoding, encoding and large derivations run on isolates; the record merge itself (a few repertoire records) and the database writes (on drift's database isolate) do not need one.
8. **Local-change trigger.** "Local change" is any write to `runs` or `repertoires` (drift table updates) while sync is on and not running, so the sync's own writes do not schedule another one.
