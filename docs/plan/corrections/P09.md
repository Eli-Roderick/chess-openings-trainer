# P09 corrections (from the P09 build thread, 2026-10-06)

1. **Prefetch at line start.** 05 §6 schedules the end-of-line candidates job "when the run reaches the user's last book move", and the mid-line job at ply d-2. The search takes 800 ms plus engine start-up, so a quick last move (or the opponent delay of a short line) would mostly miss it and the ≥ 95 % readiness target would fail. The job starts as soon as the line (or, after an alternative move, the new line) is known: same candidates, more time. It is low priority, so comparable checks still preempt it. (D-97)
2. **Reply judgement needs the best move.** `EngineJudge.judgeReply` returned only pass/loss, but the event stores `bestUci` and the result shows "Best was Nf3". It now returns the best move with the judgement; `EngineJudge.bestMove` serves the hint during a reply.
3. **Judgement failures.** The plan does not say what happens when the engine cannot judge a reply. End of line: the run is stored as a normal run without a deviation event. Mid-line: the run is still `deviated` (the rest of the line was not played) without an event; chess_core gained `RunBuilder.markDeviated()` for this. Same when the deviation leaves no legal reply.
4. **No countdown after a challenge.** The end bar's auto-advance would hide the result after 1.5 s; after a challenge the countdown does not start (Next line or Space continues).
5. **Skip line during an end-of-line challenge.** The line itself is complete, so Skip drops the challenge and ends the line normally (no abandoned run). Leaving the drill during the challenge stores the run as completed without an event.
6. **Analyse from Play on.** 01 §8.2 says "opens Analysis at the current position", which lives inside Browse. Browse takes the free-exploration moves (route `extra`) after the last repertoire node and `?analyse=1`, so the analysis opens at the play-on position with Back stepping through the off-book moves.
7. **Profile test after P08.** The Train button opens the mode sheet since P08; the profile test now starts the drill through it (fixed on the P08 PR).
