# P02 corrections (from the P02 build thread, 2026-10-06)

1. **SRS float drift.** 04 §5.2 multiplies the interval by an ease built from repeated `+0.10`; in floating point 2.5 + 0.1 + 0.1 = 2.7000000000000002, so `ceil(10 × ease)` gave 28 instead of 27. Ease is rounded to two decimals after every change and the ceiling uses a 1e-9 tolerance. (D-45)
2. **Weak-mode exclusion.** 04 §4 says "exclusion restricted to pool lines" without saying whether the recent list is filtered. It is: only recently started *pool* lines use the `min(3, poolSize - 1)` slots, otherwise non-pool lines would waste them and a just-played weak line could come straight back. (D-44)
3. **freezed and the constructor lint.** Unnamed factories cannot be named `new`; the lint-clean freezed form is `const factory({...}) = _Name;` with `const new _();` for the private constructor. Verified with freezed 4.0.1 (code generation, JSON round trip, `copyWith`). (D-46)
4. **`deriveRepertoire` signature.** 04 §8 lists a `today` argument; nothing in the derivation depends on it (SRS states are day-independent, "due today" is a query). It is omitted. (D-47)
5. **§7 engine maths in P02.** 04 says all of §1-§9 lives in `training/` and P02 tests cover §1-§9, while P02 puts engine *calls* out of scope. The pure parts of §7 (score conversion, comparable decision, deviation candidates and weighted pick, reply judgement) are in `training/engine_judgement.dart` now; P06 wires them to the engine. (D-48)
